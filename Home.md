## 📖 Welcome to Minigame Tech

This wiki is the **official documentation hub** for Minigame Tech – a curated collection of authentic recreations of classic arcade games, built from scratch in Python and C#, and distributed as free, standalone executables.

Whether you're a **player** looking to get started or a **developer** interested in the architecture, this documentation covers everything you need to know.

### Technology Stack

- **Languages:** Python 3, C#
- **Game Library:** Pygame 2.x
- **Packaging:** PyInstaller, .NET / MSBuild
- **Hosting:** GitHub Pages

## 🎯 Getting Started

### I want to play a game

1. **Download:** Visit [minigame-tech.github.io](https://minigame-tech.github.io)
2. **Extract:** Unzip the file for your operating system
3. **Run:** Execute the game file
4. **Play:** Follow in-game instructions

→ Read the **[Quick Start Guide](Quick-Start)** for detailed steps.

### I'm having trouble

Check the **[Troubleshooting](Troubleshooting)** page for solutions to common issues.
