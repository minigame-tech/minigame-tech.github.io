## 📖 About

**Minigame Tech** is a growing collection of clones of classic arcade games, written in Python, C# and distributed as free standalone executables for Linux and Windows.

Each game comes with a menu, an in-game tutorial and keyboard controls, so you can download it and start playing right away. The project started as a set of school projects (including high-school final exam work such as *Frogger* and *Pacman*) and is now a personal, continuously evolving library of retro classics.

> **Note:** the in-game interface is currently in Italian.

### Controls

| Game | Move | Confirm / Back | Goal |
|:---|:---|:---|:---|
| **Frogger** | Arrow keys | `Enter` / `Esc` | Reach the opposite bank 5 times to win |
| **Pacman** | Arrow keys or `W` `A` `S` `D` | `Enter` / `Esc` | Eat every dot and avoid the ghosts |

Both games start with **3 lives**.

## 📥 Download

No compilation or Python installation is needed.

1. Go to the official website: **[minigame-tech.github.io](https://minigame-tech.github.io)**.
2. Pick a game from the catalog.
3. Download the file for your operating system.
4. Extract the archive and run the executable.

**Linux:** if the file doesn't start, make it executable first:

```bash
chmod +x ./game-name
./game-name
```

**Windows:** executables built with PyInstaller may trigger a *Windows SmartScreen* or antivirus warning, because they are not digitally signed. This is a known false positive for unsigned executables. If you prefer, you can check the files on the [project repository](https://github.com/minigame-tech) before running them.

**System requirements:** a desktop PC running Linux or Windows, a keyboard, and a screen of at least 800×640 pixels.
