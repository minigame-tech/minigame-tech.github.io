# Security Policy

We take the security of our project, users, and community seriously. If you believe you have discovered a security vulnerability, we encourage you to report it responsibly and privately so we can investigate and remediate it as quickly as possible.

## Supported Versions

The following versions are currently supported with security updates:

| Version | Supported |
| ------- | -------- |
| Current release | :white_check_mark: |
| Previous stable release | :white_check_mark: |
| Older releases | :x: |

## Reporting a Vulnerability

Please report vulnerabilities through one of the following channels:

- GitHub Security Advisories (preferred)
- Email: security@minigame-tech.com

When reporting, please include:
- a clear description of the vulnerability
- the affected version(s)
- steps to reproduce the issue
- the potential impact or risk
- any proof-of-concept or suggested remediation

Please do not disclose the issue publicly until we have had a reasonable opportunity to review, validate, and address it.

## Response Expectations

We aim to acknowledge valid security reports within 48 hours. We will provide updates throughout the investigation and remediation process, and we will work to resolve confirmed vulnerabilities in a timely manner.

## Responsible Disclosure

We appreciate coordinated disclosure and thank security researchers and contributors who help us improve the security of our project. We are committed to handling reports professionally, transparently, and with respect for the reporter’s privacy.

## Scope

This policy applies to the project repository, associated services, and any software or infrastructure that is directly maintained by the project team. Issues affecting third-party dependencies or external services should be reported to the appropriate maintainers or vendors.
